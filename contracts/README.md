# Contracts — single source of truth

Versioned JSON Schemas (draft 2020-12) and math artefacts shared by Django, Phoenix and the
frontends. **Change a contract here first**, then regenerate consumers in the same PR.

| Path | Contract | Consumers |
|------|----------|-----------|
| `ws/v1/` | Browser ⇄ Phoenix protocol `lr.v1` (doc 10) | `packages/protocol` (generated TS), Phoenix validators |
| `wallet/v1/` | Platform ⇄ operator seamless wallet (doc 09 §6) | Django wallet adapter, operator simulator |
| `operator/v1/` | Operator API (doc 09 §4) | Django `api_operator` |
| `math/lr-crash-1/vectors.json` | Known-answer vectors for the crash formula, curve and payouts (doc 07) | Python, Elixir and TypeScript test suites |

Rules
- Within a major version: additive changes only. Breaking change ⇒ new `vN` directory.
- Multipliers are integers in ten-thousandths (`*_x10000`); money is integer minor units as strings.
- `vectors.json` is generated by `backend/scripts/gen_vectors.py` (`make vectors`); CI fails if it drifts.
- TS types are generated by `pnpm --filter @luxrocket/protocol generate` (`make generate`); CI fails if stale.
